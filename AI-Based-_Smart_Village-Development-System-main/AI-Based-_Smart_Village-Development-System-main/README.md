AI-Based Smart Village Development System

## About the Project
This project is an AI-based Smart Village Development System designed to support village development and decision-making using data analysis and machine learning.

## Features
- Village Analysis
- Development Score Prediction
- Crop Recommendation
- Employment Suggestions
- Infrastructure Planning
- Government Scheme Recommendations
- Report Generation

## Technologies Used
- Python
- Flask
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- SQLite
- HTML
- CSS

## Project Objective
The main objective of this project is to analyze village-related data and provide AI-based predictions and recommendations for better village development.

## How to Run
1. Install Python.
2. Install the required libraries.
3. Run app.py.
4. Open the provided localhost URL in a web browser.
